The high cost of Big Data infrastructure limits access for academic and
resource-constrained organisations. This paper presents an open-source
Infrastructure-as-Code framework that automates the deployment of a Hadoop-based
Data Lake on Oracle Cloud Infrastructure Free Tier ARM instances. Using Terraform
and Ansible, the framework provisions a four-node ARM cluster and installs the
OpenSource Data Platform stack via Apache Ambari, supporting multiple installation
profiles for different workload types. The architecture provides distributed
storage on the Hadoop Distributed File System and analytical processing through
Apache Spark and Hive. The Star Schema Benchmark was executed under three
configurations---Hive, Spark, and Spark with caching---to evaluate query
performance on constrained hardware. Spark consistently outperformed Hive by
margins exceeding 200~seconds per query, whereas in-memory caching offered only
marginal gains owing to insufficient memory for the largest fact table. These
results confirm the viability of zero-cost, reproducible distributed analytics
for research and education.
\end{abstract}
