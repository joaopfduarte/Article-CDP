# Reference: examples and anti-patterns

## Example subjects

- `feat(content): add methodology clarification for OCI profile selection`
- `fix(bib): correct publication year for deochake2026cloudaiinfrastructurecost`
- `docs(slides): improve talk track in results section`
- `chore(agents): rename legacy tcc rules to article naming`

## Optional body example

```text
fix(content): align SSB caching narrative with reported mean penalties

Clarifies that cache overhead occurs when lineorder cannot fit in memory.
Keeps wording consistent with benchmark table and abstract claims.
```

## Anti-patterns

- Vague subjects such as `update`, `misc`, or `final changes`.
- Mixing unrelated concerns (for example, bibliography fixes and script refactors) in one commit without rationale.
- Claiming verification steps in a commit message when they were not actually run.
